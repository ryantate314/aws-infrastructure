# Security

## Baseline controls implemented
| Control | Where |
|---|---|
| State bucket: versioned, encrypted, public access blocked, TLS-only, no logging of secrets | `bootstrap/` |
| CloudTrail multi-region management events, log file validation | `account/cloudtrail.tf` |
| IAM password policy; IAM Access Analyzer | `account/guardrails.tf` |
| Budgets and anomaly alerts | `account/guardrails.tf` |
| Permissions boundary for workload roles | `account/iam.tf` |
| GitHub OIDC (no static keys), plan vs apply roles by ref | `account/iam.tf` (optional) |
| EBS default encryption | `account/guardrails.tf` |
| VPC: default SG has no rules, no public IP by default, isolated tier, no SSH, SSM only, IMDSv2 | `envs/modules/baseline` |
| Workload buckets: private, OAC-only, TLS-only, HSTS and security headers, TLS 1.2+ | `templates/workload` |

## Rules
- No long-lived IAM user keys; humans use IAM Identity Center with MFA.
- State for everything except `bootstrap/` stays out of git. `bootstrap/` state must contain no secrets or PII (account ID and ARNs appear in it; they are identifiers, not credentials).
- Least privilege: workload roles carry the boundary; CI apply role is admin but only assumable from `main` (tighten later).
- Pre-commit: run `terraform fmt`, `terraform validate`, and a secret scanner (`gitleaks`) before pushing.

## Threat notes
- **Credential theft** is the main risk for a personal account: MFA everywhere, no keys, short sessions (1h OIDC, SSO).
- **Cost abuse** (e.g. leaked key spinning up compute): budget, anomaly alerts, boundary denies, region restriction.
- **Public data exposure**: Block Public Access on all buckets, Access Analyzer, photo delivery via CloudFront signed URLs or presigned URLs for private albums.
- **Supply chain**: pin provider versions, commit lockfiles, review `terraform init` diffs.

## Photo delivery notes
For private client galleries prefer CloudFront signed URLs/cookies (key group in CloudFront; the private key lives outside the repo, e.g. Secrets Manager at ~$0.40/mo or SSM SecureString at $0) or short-lived S3 presigned URLs generated by Lambda. Do not make the bucket public.
